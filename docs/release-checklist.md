# Проверка перед выпуском

Пройти руками на настоящем компьютере перед каждым релизом. Автотесты (`pytest`) и проверка в Windows Sandbox
этого не заменяют: здесь — настоящий принтер, бумага, телефон и интернет.

## 1. Установка
- [ ] Установщик запускается, «Установить» → ярлыки на рабочем столе и в «Пуске».
- [ ] Поверх старой версии: кнопка «Обновить», тетради и настройки на месте.
- [ ] Двойной щелчок по файлу тетради `.konspekt` открывает её в программе.
- [ ] Переносная версия: ZIP распаковать, запустить; папка «Данные» появилась рядом, установленная не затронута.

## 2. Первый запуск
- [ ] Мастер: «Учёба» — нет видов подготовки, расписания и шапки МЧС; первая тетрадь без «Самостоятельной подготовки».
- [ ] «Служба МЧС» — виды подготовки, даты через 4 дня, расписание, планы-конспекты, лист проверки.
- [ ] «Просто писать» — только текст.
- [ ] «Только PDF» — нет раздела «Принтеры», главная кнопка «Сохранить PDF».

## 3. Тетрадь
- [ ] Текст сразу появляется на листе, страницы листаются.
- [ ] Длинный текст спокойно переходит на следующую страницу (без красных ошибок).
- [ ] «Уместить на страницу» уменьшает почерк до одной страницы.
- [ ] Заголовок, пункт списка, «С новой страницы» работают.
- [ ] Тетрадь сохраняется сама и открывается из «Недавних».
- [ ] Отмена: удалить конспект → «Отменить» (или Ctrl+Z вне поля текста) — вернулся; «Вернуть» (Ctrl+Y).
- [ ] Лупа под листом / двойной щелчок: лист крупно, листание стрелками, + −, «По ширине».
- [ ] Узкое окно (не на весь экран): ничего не обрезано, кнопки переносятся.
- [ ] Длинная тетрадь (10+ конспектов): правка не тормозит, листание быстрое.

## 4. Импорт
- [ ] «Из файла»: TXT, DOCX, старый DOC, PDF, фото страницы — текст на месте; в скане «кавычки», тире, °C.
- [ ] МЧС: расписание (DOCX) → список занятий с галочками; планы-конспекты сами находят свои занятия.

## 5. Почерки
- [ ] Образцы Caveat и Bad Script видны в разделе «Почерки».
- [ ] Шаблон печатается на A4, заполненный лист по фото распознаётся, почерк сохраняется и выбирается в тетради.
- [ ] Фото листов шаблона — «С телефона» по QR-коду (телефон и компьютер в одном Wi-Fi).
- [ ] «Слитное письмо» в «Оформлении»: буквы читаются, связки естественные; выключается галочкой.

## 6. Принтер
- [ ] «Принтеры» → «Откалибровать» → «По фото»: лист распознаётся с обеих сторон (и по QR-коду с телефона).
- [ ] Проверка по фото: «Калибровка завершена» не позже второй проверки.
- [ ] Статус принтера: «Настроен точно».
- [ ] Печать конспекта: лицевые → переворот → обороты, строки в клетке на обеих сторонах.
- [ ] Второй принтер (рабочий): своя калибровка, домашняя не пропала.

## 7. Нейросеть
- [ ] Настройки → «Нейросеть» → GigaChat → ключ → «Сохранить и проверить»: «Работает».
- [ ] Другой сервис (если есть ключ): адрес, ключ, «Проверить» — список моделей подтянулся.
- [ ] «Написать по теме»: черновик появился, источники и предупреждение — в «Исходнике».
- [ ] «Сжать через …»: длинный материал → конспект на страницу; «Исходник» и «Отменить» возвращают прежний текст.
- [ ] Без интернета — понятное сообщение, программа не зависает.
- [ ] «Удалить ключ» — кнопка сжатия просит ключ снова.

## 8. Прочее
- [ ] Светлая и тёмная тема: всё читается.
- [ ] Сохранить PDF: открывается, размер листа правильный.
- [ ] Удаление через «Параметры Windows»: программа и ярлыки исчезают, тетради в «Документах» остаются.
- [ ] Рабочий компьютер: установщик запускается (или нужна переносная версия).
