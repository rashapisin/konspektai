# Цифровая подпись программы

Без подписи Windows SmartScreen пишет «Неизвестный издатель», а на рабочих компьютерах политика может вообще
запретить запуск. Платный сертификат стоит от 10–20 тыс. ₽ в год, поэтому план — бесплатная подпись для
открытых проектов от **SignPath Foundation** (https://signpath.org).

## Условия (на момент записи)
- Открытая лицензия, одобренная OSI, без платной «двойной» лицензии — у нас MIT.
- Весь код открыт (системные библиотеки можно), проект живой и уже выпущен в том виде, что будет подписан.
- Сборка полностью автоматическая и привязана к репозиторию — `.github/workflows/release.yml`.
- На странице загрузки опубликована политика подписи (раздел ниже — перенести в README при подключении).
- Издателем в подписи будет SignPath Foundation; правила нарушать нельзя — сертификат могут отозвать.

## Шаги
1. Выложить 1.0.0 на GitHub (релиз собирается сам по метке `v1.0.0`).
2. Подать заявку на https://signpath.org (форма для open source), указать репозиторий `rashapisin/konspektai`.
3. После одобрения — добавить в `release.yml` шаг подписи SignPath (их GitHub Action) перед загрузкой файлов.
4. В README — раздел «Политика подписи»: кто подписывает, что подписанные файлы собраны этим workflow из
   этого репозитория, как сообщить о проблеме.
